## Включение писем на существующем Vercel

Обработчик `POST /api/geo-leads` работает внутри сайта и использует Resend. В настройках нужного Vercel-проекта задать серверные переменные:

| Переменная | Значение |
|---|---|
| `RESEND_API_KEY` | Ключ отправки писем Resend |
| `GEO_MAIL_FROM` | Подтверждённый в Resend адрес отправителя, например `GEO <leads@ваш-домен>` |
| `GEO_FORM_ENABLED` | `true` после настройки отправителя |

Ключи не добавлять в Git и не передавать в браузер. Получатель зафиксирован на сервере. После изменения переменных нужен новый deployment. Пока настройки отсутствуют, форма явно недоступна, остаются почта, Telegram и телефон.

Подключение почтового аккаунта и production-публикация не выполнены. Доступная сессия Vercel требует входа владельца. Нужен один согласованный тест с отметкой «ТЕСТ» и проверкой фактического получения в Gmail. Принятие письма API не доказывает доставку во входящие: возможны задержка, спам или отказ доставки.

Для повторов используется idempotency key Resend (24 часа); интерфейс ограничивает повтор 23 часами. После перезагрузки при изменившейся атрибуции сервис может вернуть конфликт вместо повторной отправки — интерфейс предложит уточнить получение по прямым контактам. Отдельного хранилища заявок нет. Успех аналитики возникает только после подтверждения провайдера с ID письма.

Политика и согласие содержат данные самозанятого Колесникова Антона Олеговича и фактическую цепочку Vercel → Resend → Gmail. Тексты не заменяют проверку владельцем применимых обязанностей по локализации и трансграничной передаче перед включением сбора.

## Проверки

- `node --test tests/geo-analytics.test.mjs tests/geo-mail.test.mjs`: 13 тестов, все пройдены; успех, ошибки, таймаут, повторы, валидация и отсутствие персональных данных в событиях.
- `node node_modules/typescript/bin/tsc --noEmit -p tsconfig.geo.json`: проверка затронутых маршрутов и их зависимостей.
- `node node_modules/next/dist/bin/next build`: production-сборка. В проекте ранее отключена проверка типов в build, поэтому она запускается отдельно.
- Полная проверка TypeScript имеет 6 существовавших до правок ошибок в `calendar.tsx` и `lumina-interactive-list.tsx`; они не относятся к GEO и не скрыты изменениями конфигурации.
- В браузере проверены обе страницы при 1440×900, 390×844, 360×800. Основная кнопка помещается в первый экран, горизонтального скролла нет. Проверены переключение мини, обязательные поля, ошибка и успех на тестовом почтовом обработчике. Реальные письма не отправлялись.
- `tests/mock-mail.mjs` — только локальный перехват API провайдера для UI-проверки. Запуск: `node --import ./tests/mock-mail.mjs node_modules/next/dist/bin/next dev -p 9014` с тестовыми серверными переменными. На Vercel helper запрещает запуск; приложение его не импортирует.
- Производительность реальных посетителей, рабочая доставка и цели в production-Метрике пока не проверены. Рекламные кампании не менялись.
